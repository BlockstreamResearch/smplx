# Last Will Simplex Example

This example builds on [`examples/basic`](../basic) to show something
Bitcoin Script can't express at all: a *recursive covenant*. Where
`p2pk.simf` is a single spending condition, `last_will.simf` re-creates
itself on-chain across a whole chain of transactions, and offers three
different actions depending on which key is used.

## Overview

`last_will.simf` implements a simple inheritance scheme with three
hard-coded keys:

* **Inherit** -- after the covenant sits untouched for 1440 blocks
  (relative timelock), the inheritor's key can withdraw the funds.
* **ColdSpend** -- the owner's cold key can break out of the covenant at
  any time, with no wait required.
* **HotSpend** -- the owner's hot key can "check in" at any time,
  resetting the inheritance clock. `refresh_spend` doesn't just check
  a signature: it calls `recursive_covenant()`, which requires the
  transaction to pay back into this exact same covenant script (output 0)
  plus a real Elements fee output (output 1). This self-referential output
  check, with the covenant examining its own outputs to constrain them, is
  the mechanism with no Bitcoin Script equivalent.

For Simplex compatibility, these actions are represented here as Either
types (instantiated with Left/Right) rather than named `enum` values.

The repository structure is the same shape as `examples/basic`:

```md
root
├── simf — Simplicity smart contracts source directory
├── src — The project's Rust code (witness and transaction builders)
│   └── artifacts — Simplicity artifacts generated by Simplex (gitignored)
├── tests — Simplex tests directory
├── Cargo.toml — The project's Rust configuration
└── Simplex.toml — The project's Simplex configuration
```

### Build

```bash
simplex build
```

As with `examples/basic`, this generates `src/artifacts`, already declared as a module in
`src/lib.rs`.

### Test

```bash
simplex test last_will_test -v
```

The `-v` option adds verbose output. The test suite includes narration, with each test
showing what it's attempting and how the network responded. Several tests expect a
rejection (wrong key, broken `recursive_covenant()` check, or inheritance claimed too
early).

One test, `inherit_after_wait_succeeds`, synthetically mines 1440 blocks to make the
inheritance wait real. This should be relatively rapid with local `elementsd`.
